# Running Trajectories

Commands for executing symbolic trajectory JSONs through the simulator and
writing grounded outputs plus rendered images.

All commands assume:

```bash
conda activate robocasa
cd robocasa
```

## Single Trajectory

Run one trajectory through the executor:

```bash
python -m robocasa.utils.sim_tool_executor \
  --trajectory data_generation/task_level/data/image/20260324T031125Z/hot_dog_setup/trajectories/traj_000000.json \
  --robots 2 \
  --layout 11 \
  --style 34 \
  --seed 42 \
  --placement grid \
  --output-dir tmp/test_single
```

`--task` is optional here. If omitted, the executor reads it from the
trajectory's `composite_task` field.

### Without videos

Per-camera MP4s are generated by default for single-trajectory runs. Skip them
with:

```bash
python -m robocasa.utils.sim_tool_executor \
  --trajectory path/to/trajectory.json \
  --robots 2 \
  --placement grid \
  --skip-videos \
  --output-dir tmp/test_no_video
```

## Sweep Runs

`scripts/sweep_trajectories.py` discovers `traj_*.json` files under a dataset
directory and executes each one. Sweep mode does not generate videos.

### All trajectories

```bash
python scripts/sweep_trajectories.py \
  --input-dir data_generation/task_level/data/image/20260324T031125Z \
  --output-dir tmp/sweep_output
```

### Single task

```bash
python scripts/sweep_trajectories.py \
  --input-dir data_generation/task_level/data/image/20260324T031125Z \
  --output-dir tmp/sweep_output \
  --task hot_dog_setup
```

### Specific trajectory indices

```bash
python scripts/sweep_trajectories.py \
  --input-dir data_generation/task_level/data/image/20260324T031125Z \
  --output-dir tmp/sweep_output \
  --task hot_dog_setup --indices 0 1 2
```

### Layout/style/seed sweep

```bash
python scripts/sweep_trajectories.py \
  --input-dir data_generation/task_level/data/image/20260324T031125Z \
  --output-dir tmp/sweep_output \
  --layouts 11 56 \
  --styles 34 42 \
  --seeds 42 99
```

### Dry run

```bash
python scripts/sweep_trajectories.py \
  --input-dir data_generation/task_level/data/image/20260324T031125Z \
  --output-dir tmp/sweep_output \
  --layouts 11 56 --styles 34 42 --seeds 42 99 \
  --dry-run
```

## Output Structure

### Single trajectory output

```
tmp/test_single/
  adapted_trajectory.json
  trajectory_execution_metadata.json
  plan.json
  metadata.json
  images/traj_000000/
    0_top_view_agent_0.png
    0_room_view_agent_0.png
    0_map_agent_0.png
    ...
  room_view.mp4
  top_view.mp4
  robot0_agentview_center.mp4
  ...
```

### Sweep output

```
tmp/sweep_output/
  sweep_summary.json
  hot_dog_setup/
    traj_000000/
      adapted_trajectory.json
      trajectory_execution_metadata.json
      plan.json
      metadata.json
      images/traj_000000/
        ...
```

When multiple layouts/styles/seeds are requested, each trajectory directory gets
an additional `L<layout>_S<style>_sd<seed>` layer.

## How Images Are Generated

Images are rendered only when the trajectory contains `get_image` tool calls.
Typical pattern:

```text
get_image (before)
pick_up_object
get_image (after)
```

Each `get_image` step specifies:

- `views`
- `image_paths`

Agent-relative views such as `wrist` and `agentview_center` are mapped to the
concrete robot cameras for the acting agent. Shared views include `top_view`,
`room_view`, and `map`.

## Sweep Summary

`sweep_summary.json` records the overall counts plus one result record per run,
including task, trajectory index, scene parameters, timing, and success/failure
status.

## Important Flags

```text
--input-dir       Dataset root directory
--output-dir      Output root directory
--task            Filter to a single task directory name
--indices         Filter to specific trajectory indices
--layouts         Kitchen layout ids to sweep
--styles          Kitchen style ids to sweep
--seeds           Environment seeds to sweep
--robots          Number of robots
--placement       Placement mode; currently only `grid`
--cell-size       Occupancy-grid cell size in meters
--dry-run         Print what would run without executing
```
